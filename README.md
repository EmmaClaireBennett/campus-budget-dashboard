# Campus Budget Dashboard

A complete, offline-first budgeting dashboard for students. It stores data in the browser, summarizes spending by category, filters transactions, and exports CSV without requiring an account or API key.

## Features

- Add and delete transactions
- Category totals and monthly spending summary
- Search and category filtering
- Visual spending bars
- CSV export
- Responsive layout and empty states
- Data persisted with `localStorage`

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Privacy

Transactions stay in the browser's local storage. Use the Reset button to clear local data.
